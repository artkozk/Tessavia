# Проверки выпуска сохранности конструктора — 14.09.2026

Новый выпуск продолжает проверенную процедуру field-conversion; прежние процедуры
сохранены. Скрипт требует исходный release
`/opt/business-control/releases/20260914-field-conversion-ae9402f` и его точный SHA256
`088d817fca25ec44bfa583c694b72600feec625ab5da6fa4fb0d3d672fce3e16`.

Проверяются блокировка деплоя, SHA кандидата, backup базы/файлов/конфигурации,
свободный порт 18640, запуск кандидата на копии и побайтовая эквивалентность значений
всех 127 таблиц. Миграций нет, точная схема остаётся 070. На той же копии запускается
предыдущий бинарник и сравнение повторяется. При откате сохраняется последняя база,
включая пользовательские изменения после выпуска; backup не подменяет текущие данные.

Перед публикацией выполняются 17 синтетических проверок verifier, `bash -n`,
проверка Python, окончательные тесты приложения и браузерная приёмка. При переключении
служба останавливается и создаётся отдельная cutover-копия. Проверяются nginx,
локальный и публичный health, JS/CSS, защита API без авторизации, integrity и FK.

Запись результатов требует точный release, SHA, backup, подтверждённые тесты и
описание реально выполненных GUI-сценариев. Закрываются только две дочерние задачи
черновика и защиты типа. Общий конструктор сохраняет статус; задача освобождения
лимита блоков остаётся запланированной. Доступ, пользовательская база и резервные
копии не выносятся с рабочего сервера. Физические телефоны не заявляются проверенными.
