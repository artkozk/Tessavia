1. Добавлена личная библиотека без предварительно установленных конфигураций

2. Сервер извлекает выбранный корень, проверяет внешние зависимости и сохраняет
   только структуру. HTTP-проверка исключает маркеры реальной записи, внешнего
   блока и личного числа из ответа компонента.
3. Атомарная вставка создаёт новые источники и блоки и сохраняет текущий черновик.
   Два экземпляра имеют независимые ID, отметки и схемы. Исходная страница с

4. Повторяющиеся запросы защищены ID и хешем. Проверены обычный retry, изменённое
   тело, CAS-конфликт без оставленных досок и шесть параллельных одинаковых POST.
5. Добавлен интерфейс «Сохранить как свой блок» / «Мои блоки» с предпросмотром и

6. В процессе проверки обнаружена опасность неизвестного ответа: после reload
   ревизия сервера может быть новее черновика. Добавлено восстановление квитанции
   без переноса старого черновика на новую ожидаемую ревизию. Исполняемый тест
   подтверждает, что повторный обычный Save по-прежнему получает старую ревизию.
7. Выполнены gofmt, проверки синтаксиса JS и diff --check. Целевые Go-тесты

## Сценарии браузерной приёмки для общего выпуска

1. В синтетическом личном аккаунте создать пустую страницу, добавить группу,
   трекер с двумя пунктами и прогресс по этому трекеру. Через свойства сохранить
   группу в «Мои блоки» с длинным названием.
2. В другой пустой личной странице открыть «Мои блоки», посмотреть сохранённую
   структуру и вставить её. Отметить один пункт. Вставить вторую копию: у неё
   нулевой прогресс, у первой прежняя отметка. Reload сохраняет обе независимо.
3. Изменить заголовок одной копии: вторая копия и библиотечный предпросмотр
   сохраняют исходный заголовок. Сохранить принимающую страницу обычным Save.
4. Группа с расчётным листом: сохранить структуру, в исходнике ввести число;
   вставка на другую страницу содержит формулу и пустое поле ввода.
5. Группа со списком/формой: вставка создаёт новую пустую доску; записи и права
   исходника не переносятся. Установленная копия через обычный набор страницы
   должна снова получить самостоятельную схему.
6. Создать прогресс вне группы с внешним источником, сохранить только прогресс:
   понятная ошибка. Включить оба блока в одну группу и повторить успешно.
7. На 320 px проверить длинное имя, список, предпросмотр, кнопку возврата и
   конечное подтверждение. Диалог не должен расширять страницу по горизонтали.
8. Во время загрузки каталога перейти в другое пространство или закрыть окно.
   Ответ не должен вернуть пользователя в старый редактор.

программирования.
