# Поиск разговора в списке — SC-69

Этап задачи e402d353a684b074f852fa1fd277d895, перечитанной через production API.
В списке нет поиска нужного собеседника или группы: при длинном списке остаётся
прокрутка. Поиск сообщений открытого диалога не решает этот сценарий. Добавляем
строку «Найти диалог» внутри списка, над разговорами; обычный поиск сообщений
сохраняет своё назначение в заголовке открытого диалога.

Поиск фильтрует только уже разрешённый сервером список текущего проекта: название,
имя собеседника и название связанной карточки. Слова запроса должны встречаться
в любом порядке, регистр и ё/е не различаются. Порядок закреплений сохраняется.
Нулевой результат объясняется рядом, очистка возвращает весь список. Фильтр не
переключает открытый разговор, не читает скрытые совпадения и не меняет черновик.

Запрос живёт в памяти текущего пользователя и проекта: переключение контекста и
перезагрузка его очищают. Опрос сервера не сбрасывает запрос, фокус или открытый
мобильный список. Выбор результата закрывает список на телефоне и открывает только
выбранный разговор. Сохраняются отдельные черновики сообщений. Новых API/таблиц нет.

Проверить: длинное название, кириллица и несколько слов, пустой результат/очистка,
закреплённая группа, возврат к DM с черновиком, внешний серверный refresh во время
ввода, два проекта и 320/1280 px. Не считать это глобальным поиском сообщений,
архивом или завершением большой задачи чата.
