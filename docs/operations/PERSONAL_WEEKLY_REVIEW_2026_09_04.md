# Выпуск личного недельного обзора — 04.09.2026

## Подготовленная область выпуска

Выпуск добавляет личную вкладку недельного обзора, два защищённых API и
миграцию 052 с двумя новыми приватными таблицами. Существующие таблицы выпуска
051 считаются исходными и должны быть побайтно эквивалентны по всем прежним
столбцам после сухого запуска. Командные назначения и общий командный ритуал
Review в этот выпуск не входят, поэтому каноническая карточка не завершается.

## Локальная приёмка

- `go test ./...` — пройден после реализации первого этапа;
- `go vet ./...` — пройден;
- Node-тесты — 182 сценария до исправления подписи нулевого результата; после
  добавления регрессии выполняется финальный полный прогон;
- 25 чтений локального обзора: median 3,94 мс, p95 4,74 мс, max 4,94 мс;
- браузер: обычная ширина и 320 px, сохранение выбора и reload, длинные строки,
  привычка без успешного дня, отсутствие горизонтального переполнения и ошибок
  консоли.

Тестовая база находится только в локальном `.artifacts` и не переносится на
production. Рабочая проверка после переключения релиза должна использовать
краткоживущую сессию владельца, только читать существующие источники и создать
отметку доказательства в уже существующих задачах. Новые пользовательские дела,
привычки, ожидания, решения или риски на рабочем сервере для проверки не
создаются.
