# SC-83. Условный показ блоков по личному прогрессу

## Зачем сделан этот этап

Пользователь требует конструктор поведения, а не только оформление. После SC-82 зарегистрированы направления привязок/видимости и составных действий. Первый ограниченный сценарий направления 2ad192a4298615883945e23a87d8ecd2 — раскрыть следующий этап после личных отметок в другом блоке. Узкая задача: 05d64b353b1627ee64611c199e63af28. Этот этап не выполняет всё направление привязок данных и не создаёт готовый набор за пользователя.

Например, пользователь добавляет «Подготовка» с двумя пунктами, а затем текст, форму или следующий список. У второго блока выбирает «Когда показывать блок» → «Показывать при условии» → «Подготовка» → «Выполнено, %» → «Равно» → 100. Пока отмечен один пункт, второго блока нет. После второго пункта он появляется; снятие отметки снова убирает его из представления. Содержимое и настройки не удаляются.

## Контракт и ограничения доступа

PageAppBlock.visibility — необязательная декларация source/metric/operator/value. Источник — другой блок «Пункты и отметки». Показатели: checked (выполнено), remaining (осталось), percent (процент). Сравнения eq/ne/gt/gte/lt/lte; целый порог 0–500 для числа пунктов, 0–100 для процентов. Доля вычисляется без округления: 199 из 200 не выполняет условие 100%. Скрытые пункты не участвуют. Если видимых пунктов нет или источник недоступен, условие не выполнено. Ручное скрытие блока имеет приоритет над условием.

Сервер валидирует источник, метрику, оператор, диапазон, отсутствие самоссылок и циклов зависимостей. Цикл запрещается, потому что он способен спрятать все начальные шаги. Условие читает личные отметки текущего человека, а не результаты автора страницы. Отметки остаются в штатной таблице page_app_marks, изолированной пользователем и страницей.

**Условный показ не является правом доступа.** Определение страницы, включая текст невидимого блока, доступно тому, кто имеет право читать страницу. Скрытие не запрещает действия прямым API и не заменяет права на записи/формы. Это прямо объясняется в редакторе. Для приватных данных нужны существующие права пространств/источников; использовать условие как защиту секрета нельзя.

Список, форма и источник данных не монтируются, если их блок не показан. При изменении отметок страница заново вычисляет показ. Кнопка перехода к отсутствующему блоку отключается с видимым пояснением, а не молча ничего не делает. Пустое представление с условиями объясняет, что блоки зависят от отметок, вместо предложения создать якобы отсутствующие блоки.

## Настройка и проверка без побочных действий

Раздел условия свёрнут у блоков без правила. После включения доступны источник, показатель, сравнение и порог. Снятие флажка убирает правило. В процессе UI-проверки замечено, что выключение закрывало сам раздел и прятало флажок; исправлено, панель остаётся открытой после переключения. «Отменить изменения» сохраняет опубликованное правило. Обычный черновик включает visibility и восстанавливается явно после reload; проверка ревизии не изменена.

В предпросмотре появился раздел «Проверка условий». Для участвующих источников пользователь вводит предполагаемое число выполненных пунктов. Предпросмотр синтезирует временные отметки, меняет показ и прогресс, но ничего не сохраняет в личную историю. Значения ограничены числом видимых пунктов. Состояние проверки не входит в черновик или набор: это инструмент проверки, а не результат пользователя.

Библиотека наборов, напротив, показывает условное содержимое с подписью правила, чтобы человек до установки видел состав сценария. Скрытые вручную блоки сохраняют прежнее поведение предпросмотра. При установке правило и ссылки между блоками сохраняются в независимой странице; ID блоков локальны странице, поэтому перенос ID между страницами не смешивает личные отметки. Результаты автора и состояние симуляции не копируются. Установленная копия может снять правило без изменения оригинала.

7. На 320×800 просмотрены этап, длинный заголовок, редактор, выпадающее меню показателей, выключение условия и чтение текста. Меню помещается в экран. После проверки viewport сброшен. Реальные телефоны не использовались.
