# Календарь, планы и связанные заметки

## Цель выпуска

Пользователь должен сам пройти цепочку: создать команду и проект, создать доску,
добавить карточку со сроком и увидеть её в календаре. Для личного использования:
запланировать поездку на выходные, написать список покупок и открыть этот список
из самой поездки. Наличие отдельных API не считается завершением этих сценариев.

## Решения и причины

1. Календарь получает самостоятельный пункт меню и прямой переход из доски и
   личного пространства. Старые представления на 12 недель и год сохраняются.
   Новый пункт можно скрыть настройкой меню; существующие скрытые пункты и порядок
   пользователя не сбрасываются. Команды и проекты доступны отдельным действием.
2. Личный и проектный календари разделены переключателем. Личные планы и заметки
   не становятся видны коллегам даже при привязке к общей карточке. Скрытие меню
   не заменяет проверку доступа на сервере.
3. Проектный календарь использует срок исходной карточки, а не создаёт её копию.
   Можно назначить день существующей карточке. Фильтры доски, ответственного и
   состояния не меняют записи. Цвет показывает выбранную категорию отображения.
4. Личный план может быть без даты, занимать день/период целых дней или иметь
   точную дату и время. `startDate` и `endDate` являются календарными датами без
   часового пояса. Старое `dueAt` остаётся точным моментом; смешивать два режима
   нельзя. Цвет плана хранится отдельно. Старые планы сохраняют прежнее поведение.
5. Связь видна с обеих сторон в личном пространстве. Экран плана собирает описание,
   связанные заметки и переходы. Создание заметки из плана сохраняет заметку и
   связь одной транзакцией: не допускается тихое появление несвязанной заметки.
   Существующую заметку можно привязать после создания, не копируя текст.
6. Поиск связей возвращает только записи доступных проектов. После отзыва доступа
   название карточки больше не возвращается в личных связях. Сама связь в базе
   не удаляется. Переход к разрешённой карточке учитывает её проект.
7. Месячная сетка ограничена 42 днями, на телефоне подробности выбранного дня
   расположены ниже. Ни количество записей, ни длинное название не расширяют экран.
   Назначение срока доступно без перетаскивания, включая сенсорный экран.

## Проверка перед выпуском

- Создание пустой команды, доски, карточки, назначение и изменение срока.
- Личный двухдневный план, новая и существующая заметки, обратная связь из заметки.
- Отказ привязки к чужому плану/недоступному проекту, отзыв проектного доступа.
- Валидация дат, сохранение старых сроков при обновлении статуса, повторное связывание.
- Настройка страницы календаря на ПК и телефоне без сброса остальных настроек.
- Экраны 320, 390 и 1280 пикселей, фильтры поверх доски, повторное открытие и сохранность данных.

## Границы

Это выпуск базового связанного сценария для первой демонстрации. Синхронизация
с внешними календарями, повторяющиеся события, приглашения гостей и автоматическое
изменение планов нейросетью сюда не входят. Автоматические догадки не создают связи
без выбора пользователя. Результаты проверок и выпуска фиксируются отдельным
дополнением в операционной документации, а не задним числом в этом плане.
