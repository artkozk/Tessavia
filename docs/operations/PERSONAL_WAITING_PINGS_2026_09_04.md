# Выпуск подтверждённых напоминаний по ожиданиям — 04.09.2026

## Подготовленная область

Выпуск добавляет миграцию 053, POST отправки, варианты получателей и историю в
детали ожидания. Фильтр уведомлений расширяется новым приватным типом, который
виден только получателю с действующим доступом к указанному стартапу. Остальные
уведомления продолжают использовать прежние правила личного или проектного
источника.

Новые таблицы на сухой копии должны быть пустыми. Все прежние столбцы и строки
сравниваются до и после запуска кандидата. Production-проверка не отправляет
тестовое напоминание реальному участнику: она сверяет доступные варианты с
членством, читает существующие квитанции, проверяет закрытые API и завершает
каноническую карточку только по фактическому релизу.

## Локальная приёмка

- `go test ./...` — пройден, включая точное проектное членство, подтверждение,
  приватный текст, повтор ключа, чужое ожидание и отзыв доступа;
- `go vet ./...` — пройден;
- 194 Node-сценария — пройдены; новый сценарий проверяет предварительный текст;
- реальный браузер — показан компактный блок в существующем диалоге, выбор
  стартапа/участника, приватный текст по умолчанию, явное добавление названия,
  успешная отправка и одна строка истории;
- локальное тестовое уведомление создано только в `.artifacts/pagination-preview.db`.

Фактические commit, release, SHA-256, backup, сухой прогон, публичная проверка и
итог карточки будут добавлены после переключения рабочего сервера.
