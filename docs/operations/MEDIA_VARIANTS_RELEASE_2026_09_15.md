## Что проверяется

1. Карточки всех типов, личные заметки и медиаблоки используют один сценарий:
   добавить именованный вариант, загрузить новую версию с пометкой,
   посмотреть дату/автора, выбрать версию, сравнить два изображения.
2. Старые файлы остаются самостоятельными вариантами без массовой перезаписи.
   Выбор не меняется сам после загрузки. Архивирование обратимо.
3. Каждый запрос, включая открытие самого файла и повтор ранее отправленной
   операции, проверяет текущие права. Личные материалы не появляются в команде.
   Набор переносит структуру блока, не чужие файлы.
4. Файл и подпись сохраняются на устройстве до подтверждения двух шагов:
   загрузки и привязки к версии. Повтор использует прежние ключи. Конфликт
   не перезаписывает чужое изменение и не требует повторной загрузки файла.
5. Список следует за полем, выбирает свободную сторону и сохраняет форму.
   Доступное обновление остаётся в общих настройках и снова предлагается
   после возвращения из другого приложения. Черновик не теряется автоматически.

## Финальные проверки перед выпуском

Все перечисленные выше исправления внесены. Общие проверки: **705/705 Node
PASS**, **467 Go PASS** (включая вложенные сценарии, четыре тестовых пакета),
`go vet ./...` PASS. Дополнительная проверка встраивания web-ресурсов PASS.
Тест буквального текста обработчика нормализует CRLF/LF; он продолжает
проверять остановку распространения Escape перед закрытием списка.

Финальная ручная проверка использовала новый локальный origin
`127.0.0.1:38576`, чтобы кэш предварительной сборки не подменял финальные
ресурсы с тем же ещё не опубликованным номером выпуска. В карточке
счётчик изменился **3 → 4** сразу после подтверждения загрузки. Выбор двух
изображений в окне истории сохранил фокус на втором флажке. Первоначальная
ошибка автоматического нажатия была вызвана поиском флажков без ограничения
открытым диалогом: выбирался элемент фоновой карточки. Повтор с ограничением
окном истории прошёл; это различено с реальным исправлением перерисовки.

Отдельная проверка финансов: отмена закрытия формы вернула сумму1200,
отправителя и пометку без изменений; тестовый доход не создавался.
На320 ширина прокрутки диалога равна ширине окна, длинные имена переносятся
в списке. Сборка Wiki подготовила283 страницы до итоговых дополнений.

Проверка безопасности выявила обход архивного варианта через старый адрес
файла медиаблока. Старые маршруты списка, состояния и скачивания теперь
применяют те же права архива. Отдельно удалённую версию разрешено смотреть
только при сохранённых правах, но её нельзя выбрать текущей; интерфейс это
отражает до отправки запроса. Дополнительно проверяется допустимость
возврата прежнего бинарника при наличии новых архивных данных.
