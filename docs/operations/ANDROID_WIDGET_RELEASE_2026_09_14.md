# Android-виджет и единый центр настроек — 14.09.2026

## Основание и границы

Пользователь повторно указал, что «Добавить в меню» не должно быть отдельным
пунктом боковой панели, и попросил вернуться к приложениям и системным виджетам.
Проверка обнаружила законченный web-этап (PWA, быстрые ссылки и Web Push),
но отсутствие Android/iOS-проектов. Наличие значка сайта не засчитывается
за выполнение требования о живом виджете.

Этот этап реализует Android-приложение **Tessavie Widgets** и системный
AppWidget для выбранного пользователем блока конструктора. Поддерживаются
«Пункты и отметки» (`tracker`) и «Прогресс» (`progress`), только чтение.
Пользовательские страницы и готовые наборы автоматически не создаются.
Виджет открывает Tessavie и обновляет снимок; изменение отметок выполняется
на сайте. Переход сразу к конкретному блоку, все остальные виды блоков,
FCM/APNs, звонки и выпуск в магазинах в этот этап не включены.

## Интерфейс и сценарий

1. Боковая панель содержит выбранные разделы, без «Добавить в меню».
   Редактирование доступно через **Настройки → Интерфейс → Меню и разделы**.
   Внутри сохраняются добавление страницы, наборы, порядок и профили ПК/телефона.
2. В **Настройки → Личные настройки → На телефоне** пользователь скачивает
   Android APK, выбирает собственную страницу и поддерживаемый блок, при желании
   указывает название телефона и получает одноразовый код на пять минут.
3. В системной настройке добавленного Android-виджета вводится этот код.
   Виджет получает отдельный доступ на 90 дней, не пароль и не браузерную сессию.
4. Данные хранятся на телефоне с шифрованием Android Keystore. Снимок имеет
   время последнего успешного чтения; сохранённая копия помечается явно.
   Периодическое обновление планируется системой, мгновенная постоянная
   синхронизация не обещается. Есть ручное обновление.
5. «Отключить» в том же окне отзывает выбранный доступ. При следующем
   успешном соединении с ответом 401/403 приложение очищает старый снимок.
   Обычный выход из браузера не отключает другое устройство; изменение пароля
   отзывает все виджеты аккаунта. При отсутствии сети невозможно немедленно
   стереть уже полученные данные на удалённом телефоне.

В коде страницы нет автоматического обращения к буферу обмена, копирование
выполняется только кнопкой. Код не попадает в URL, localStorage, документацию
или журналы. Запоздалые ответы после закрытия, смены аккаунта/пространства
не открывают прежний код. Потерянный ответ создания не выдаётся за неуспех
без возможной записи: интерфейс предлагает сначала проверить подключения.

## Подготовленная сборка Android

Предварительная версия `0.1.0-preview`, `versionCode=1`, Android 8+ (API26),
compile/target API34. APK не имеет флага debuggable; подписан существующим
локальным Android Debug сертификатом для проверочной установки.
Это не постоянная подпись магазина. Ключ не добавлен в репозиторий.

- Файл сборки: `mobile/android/app/build/outputs/apk/preview/app-preview.apk`.
- Размер: **35 440 байт**.
- APK SHA256: `c5f9580cb7c3a7688709f8baa438403fd8de71c9e2595539b217c42b466412f4`.
- SHA256 сертификата: `858ee34e9a8877e6a27667f646ee5cdf9476be84b09323d02e79f0d48dc035a5`.
- Адрес публикации: `/downloads/tessavie-widgets-preview.apk`.

`deploy/publish-android-widget-apk.py` принимает только отдельно загруженный
APK с ожидаемым SHA, сохраняет старую конфигурацию nginx на том же VPS,
добавляет точный download-location, проверяет `nginx -t`, перезагружает nginx
и повторно сверяет публично скачанный файл. При ошибке возвращает прежнюю
конфигурацию и прежний APK. Общий deploy-lock исключает одновременную запись
с обычным выпуском приложения. Установка на телефон не выполняется удалённо.
