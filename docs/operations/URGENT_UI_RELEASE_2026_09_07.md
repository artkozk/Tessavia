## Причины и действующее поведение

1. `navigateToView` наследовал последний `calendarScope`. После личного календаря
   этот параметр оставался personal даже в команде. Теперь переход без явно
   указанного scope определяет его по активному пространству. Явные ссылки
   в личный календарь сохраняют прежнюю семантику. Это сохраняет выбранную
   пользователем команду и не смешивает личные и командные данные.
2. Grid внутри ограниченной по высоте колонки распределял доступную высоту
   между всеми карточками. На 12 карточках измерено 25 px при содержимом 188 px.
   Для строк добавлено `grid-auto-rows: max-content`: карточка получает нужную
   высоту, а колонка прокручивается. Исправление распространяется на канбан
   рабочей очереди и пользовательские доски.
3. Панель фильтров шириной 360 px выравнивалась правым краем по кнопке слева.
   Теперь на desktop она открывается от левого края кнопки. Мобильный режим
   сохраняет фиксированную панель с отступами от краёв экрана и прокруткой.
   Это исправляет доступность существующих элементов без новой панели управления.
4. Версии оболочки, CSS, импортов и Service Worker обновлены до
   `20260907-urgent-ui-1`, чтобы браузер получил согласованный набор файлов.
