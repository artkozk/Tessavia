# Исправление масштаба кругов календаря

## Запрос и область выпуска

3 сентября 2026 пользователь прислал календарь в формате кругов при 40%:
даты 10-30 переносились вертикально, а контуры превращались в овалы.
Задача в проекте разработки `bizflow-team`:
`fbdacf516d97e8534f1576059ac3ed4b`, ответственный `artkozk`.
Маркер: `[release:calendar-circle-scaling-2026-09-03]`.
Это отдельное исправление, а не завершение всего конструктора или аудита.

## Диагностика

1. Дефект воспроизведён в локальной копии интерфейса на синтетической учётной
   записи. Production-данные для браузерных экспериментов не копировались.
2. При 40% кнопка имела размер 28 x 28 px, внутренний круг шириной 16,4 px.
   Унаследованный `overflow-wrap: anywhere` разрешал разрывать двузначную дату.
   Автоматическая строка Grid увеличивалась, высота круга доходила до 27,55 px.
   Однозначная дата при тех же настройках оставалась круглой.
3. После добавления тестовой карточки на 10 сентября обнаружено отдельное
   перекрытие: счётчик записей занимал верхнюю правую часть самой даты.
4. Проверка мини-календаря выявила, что настройки сохраняли 40%, но размер
   оставался 100%. CSP блокировала масштаб в HTML-атрибуте style. Изменение
   колесом работало через CSSOM, поэтому ошибка проявлялась при открытии.

## Изменения и причины

- У круга задано стабильное соотношение сторон и минимальный диаметр 22 px.
  Автоматические строки кнопки больше не растут от содержимого, дата не
  переносится. При 100% прежний диаметр 32,8 px сохранён.
- Числовой счётчик вынесен выше даты. Сетка резервирует 8 px сверху/снизу и
  вертикальный промежуток между строками. Это сохраняет и дату, и число
  записей, без скрытия информации и без обрезания в первой строке.
- Мини-календарь применяет исходный масштаб через существующий подход CSSOM.
  CSP не меняется; настройки не удаляются и не мигрируются.
- Обновлены версии ресурсов до `20260903-calendar-circles-1`, чтобы после
  обновления страницы браузер запросил исправленные CSS и JS.
- Добавлены проверки геометрических ограничений и способа установки масштаба.
  Они дополняют, но не заменяют проверку реальных размеров в браузере.

## Порядок проверки

1. Запустить `go test ./...`, `go vet ./...`, `node --test web/*.test.cjs`.
2. Проверить месяц при 40, 50, 60, 70, 80, 90, 100% на ширинах 1440, 390, 320 px:
   круглость контура, размещение цифр, отсутствие перекрытия счётчика,
   горизонтального выхода страницы и лишней внутренней прокрутки.
3. Проверить редактор страницы, полный экран, Ctrl+колесо, открытие дня.
4. Проверить 84 дня цикла, 365 дней года и мини-календарь с сохранённым масштабом.
5. На сервере сделать резервную копию базы, загрузок и окружения. Сначала
   запустить кандидат на копии базы и сравнить содержимое всех существующих
   таблиц. При успешной проверке переключить release под блокировкой деплоя.
6. Проверить локальное и публичное HTTP, новые ресурсы, доступность логотипа,
   закрытость личного API без сессии, целостность базы и внешний health.
7. Только после выпуска добавить результат в задачу и отметить её выполненной.

## Ограничения

Мобильная проверка выполняется в Chromium на узких viewport, а не на физических
iPhone и Android. Ограничения CSS фиксируются тестами исходных ресурсов;
геометрия и нажатия дополнительно проверяются в живом браузере. Этот выпуск
не включает незавершённые изменения жизненного цикла команд из основной
рабочей директории. Сохраняются утверждённый логотип Tessavie, прежняя палитра,
открытая регистрация без кода и все пользовательские настройки.

Фактические результаты и сведения о deployment дополняются ниже после проверки.

## Локальная проверка выполнена

- `go test ./...` и `go vet ./...`: успешно. JavaScript: 68 тестов успешно.
- 21 сочетание месячного календаря (1440/390/320 px, все семь масштабов):
  30 дат остаются круглыми; текст помещается; счётчик не пересекает текст даты
  и границы сетки; горизонтального выхода страницы и лишней прокрутки нет.
- Редактор и полный экран на 40%: те же проверки успешны.
- Год (365 дней) и цикл (84 дня): 40/100%, 1440/320 px, без деформации,
  перекрытия счётчика и горизонтального выхода страницы.
- Ctrl+колесо меняет 40% на 50% только у календаря под указателем.
- Нажатие 10 сентября открывает рабочую область именно 2026-09-10 с одной
  назначенной тестовой карточкой; пустой день и возврат назад также проверены.
- Мини-календарь: добавление через библиотеку, круговой вид, 100% (28 px),
  сохранённые 40% (20 px), повторное открытие страницы и переход к дню успешны.
- Скриншоты проверены визуально. Измерения выполнены в браузере при действующей
  CSP, без подмены стилей. Для последнего кандидата использован новый локальный
  адрес, чтобы ранее закэшированный CSS не исказил проверку.
