# Проверки выпуска преобразования полей — 14.09.2026

Процедура продолжает проверенную схему выпуска мобильных привычек. Исторические
скрипты не изменялись; новые файлы имеют префикс `field-conversion`.

`deploy-field-conversion-20260914.sh` требует точный предыдущий release
`/opt/business-control/releases/20260914-mobile-habits-b66b33c` и SHA256
`51e1c18c2c2433f8504bf46faff2bc48798717eb0f5d1464d39d0bf9c28b066f`.
Проверяются блокировка деплоя, SHA кандидата, резервные копии базы/загрузок/конфигурации,
свободный порт 18639, запуск кандидата и прежнего бинарника на копии, точная схема
070 и неизменность всех таблиц при старте. Преобразования не запускаются на
реальных пользовательских полях ради теста. Проверяются доступность нового модуля,
версия кеша, API 401 без авторизации, health, nginx и служба после переключения.

При неудаче после переключения сначала останавливается служба; если это невозможно,
симлинк не переключается. Проверяется совместимость последней базы и откатывается
только бинарник. Существующие типы, записи и история читаются предыдущей версией;
последующие данные пользователя не заменяются старой резервной копией.

`verify-field-conversion-database.py` сверяет 127 таблиц, типы и значения SQLite,
внутренние таблицы, объекты схемы и миграционные квитанции. 17 синтетических
проверок прошли после подготовки процедуры. Итоговая сборка проверяется повторно.

`record-field-conversion-20260914.py` требует результат GUI, Go/Node/vet, сверку
входных файлов сборки с коммитом, backup, health и установленную версию. Только
после этого закрывает указанную дочернюю задачу, сохраняя статус общего родителя.
Записываются доказательства и квитанция. Доступ к серверу используется по текущему
операционному контракту; секреты не записываются в Git или отчёты.

## Уточнение перед выпуском

Независимая проверка процедуры обнаружила устаревший маркер интерфейса в пробном
запуске предыдущего бинарника: ожидалась версия финансов вместо версии мобильных
привычек. До запуска деплоя проверка исправлена на
`app.js?v=20260914-mobile-habits-1`, соответствующую точному предыдущему release.
Это сохраняет проверку отката и предотвращает ложный отказ до переключения службы.
Исходники приложения и собранный бинарник не менялись; их соответствие новому
коммиту повторно проверяется по всем входным файлам сборки.
