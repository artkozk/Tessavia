# Сегодня: повторения и действительная занятость — 07.09.2026

Продолжение календарной задачи 40842b928756f5898e49a6ea09629584, прочитанной
через действующий API перед изменениями. Задача остаётся большой открытой целью.
Ранее календарь показывал прогноз серии, но Сегодня использовал только реальные
личные карточки: свободное время могло противоречить календарю. Это мешает
планированию личной жизни вместе с работой — основной цели платформы.

## Правила этого этапа

1. Сегодня получает прогноз текущего дня и семи следующих дней из того же
   серверного шаблона, что месяц и день. GET ничего не материализует. Переносы,
   пропуски и остановки используют прежние правила исключения номинальной даты.
2. Прогнозы хранятся отдельно от реальных личных карточек в ответе API и UI.
   Строка обозначена как повторение по серии, открывает знакомый предпросмотр.
   До явного открытия экземпляра нет фиктивной галочки завершения/выбора фокуса.
3. Занятость учитывает личные события, прогнозы и личные временные блоки
   назначенной работы доступных проектов. Работа выбирается общим с календарём
   правилом доступа, включая пользовательские типы конструктора. Выключение
   показа работы не превращает её интервалы в свободные; чужие данные не читаются.
4. Объединяются пересекающиеся интервалы, а не суммы длительностей. Границы дня
   могут проходить через полночь. Учитываются часовой пояс и события всего дня.
   Работа без интервала, завершённая и недоступная работа не резервирует время.
   Без границ дня свободное время остаётся неизвестным. Ошибка чтения не должна
   превращаться в ложный свободный день.
5. Расписание и список сохраняют палитру и компактные кнопки платформы, длинный
   текст переносится. Сохранённые пользовательские раскладки не сбрасываются.

Проверка до выпуска: API без вставок, прогноз/перенос/остановка, чужой аккаунт,
отозванный доступ, объединение занятости, ночь, неизвестные границы; UI открытие
из Сегодня без предварительного захода в календарь, длинное название и 320/1280 px,
отсутствие действий изменения виртуального ID. Результаты добавляются ниже.

Мини-календарные виджеты, несколько рабочих сеансов одной карточки и внешние
календари остаются отдельной работой. Этот выпуск не означает готовность всего
календаря или конструктора. Схема данных не меняется, штатный деплой сравнивает
все прежние строки на копии и сохраняет резервную копию до переключения.
