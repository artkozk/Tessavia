## Редактор

Заметка, план и проектное входящее используют один contenteditable-root.
Первый блок является местом необязательного заголовка; оставшиеся блоки
составляют Markdown-текст. Заголовок не отдельный видимый input/textarea.
Enter в заголовке перемещает курсор в текст; ввод в середине заголовка
переносит его правую часть в первый абзац. IME не перехватывается.
Обычные абзацы, форматирование и отмена/повтор используют существующий
редактор, общий снимок содержит и заголовок, и текст.

Имена title/body/notes/description остаются скрытыми полями для совместимости
API и локальных черновиков. Черновик восстанавливает весь лист независимо
от порядка полей. Escape сохраняет его прежним механизмом без повторного
подтверждения. Даты, закрепление, цвет плана и связи не переносятся в текст.
Заметки отправляют expectedUpdatedAt; устаревшее сохранение возвращает 409
и не уничтожает черновик. Старые API-клиенты без версии сохраняют совместимость.

Миграция 031 добавляет title_generated в notes, plans и records.
Служебное название по первой строке сохраняется для списков/поиска/связей,
но не вставляется в редактор. Явный заголовок всегда показывается.
Старые записи получают false: достоверно отличить ранее введённый заголовок
от автоматически полученного невозможно, поэтому исторические названия
не скрываются по догадке и не переписываются. Пользователь может очистить
такой заголовок при редактировании, сохранив основной текст.

## Команды и права

Подготовленные 027/028 включаются только после проверки. Каталог команд
не зависит от назначения проектов. Обычный участник видит команду и может
выйти, даже если ни одного проекта ему не назначили. Настройки доступны
из «Команды и проекты» и группы команды в переключателе.

Владелец выбирает проекты участника на вкладке «Участники».
Администратор имеет доступ ко всем проектам, поэтому для ограниченного
доступа используется роль «Участник». Выход находится в «Настройки».
Владелец сначала передаёт владение активному участнику либо удаляет команду.
Удаление логическое, восстановление доступно владельцу в удалённых командах;
старые приглашения не оживают. При выходе активные назначения переходят
владельцу с историей, авторство и завершённая работа сохраняются.

Проверки доступа действуют не только в интерфейсе: отзываются членство
проектов и приглашения уходящего участника. Удалённая команда не выдаётся
через прямые проектные API, личные связи/подбор, уведомления и профиль.
Последние три обходных пути найдены при текущем аудите и исправлены.
Потеря доступа к выбранному проекту не блокирует личные API и аккаунт.
Поздние ответы не заменяют данные уже выбранного пространства.

Ограничение: отдельного списка читателей одной карточки пока нет.
editPolicy ограничивает редактирование, а не чтение. Для разделения видимости
в этом выпуске используются проекты с разными участниками. Сквозная ACL
карточек, включая поиск, граф, файлы, экспорт и AI, остаётся открытой задачей.

## Переключатель

Закрытый переключатель показывает только текущий проект. В личной области
остаётся «Только вы». Команды сохраняются как группы раскрытого списка.
Имена команд и проектов в базе не изменяются. Это осознанное отличие от
предыдущего выпуска e492ac4 по новому замечанию пользователя.

## Проверки и публикация

Проверяются Go-тесты и vet, Node-тесты, синтаксис, браузер ПК/320/390 px,
сохранение/повторное открытие, пустой заголовок, Enter, undo/redo, Escape,
черновики и роли. Тестовые данные создаются только локально.
Физические Android/iOS и их экранные клавиатуры не проверялись.

Деплой использует lock, проверку предыдущего release, backup базы/uploads/env,
запуск на копии и сравнение всех старых строк по старым колонкам.
Допускаются только миграции 027, 028, 031 и их новые столбцы/пустая таблица.
Никакой клиентский контент не мигрирует и не удаляется.
Nginx, кэширование, палитра, логотип и регистрация без кода не меняются.
Фактические результаты и идентификатор публикации добавляются после проверки.
