# Конструктор: начальные значения полей

Этап существующей задачи a288364706d6c9f0ff683003aea39009, прочитанной через
production API 7 сентября. Новый запрос владельца разрешает развитие конструктора.
Цель этого этапа — убрать повторный ввод одинаковых значений в командном процессе:
например, канал обращения, валюта текстом или стандартный набор услуг. Это общая
настройка поля доски, а не личная настройка вида страницы.

## Поведение

После создания поля администратор может включить начальное значение в его
настройках. Оно подставляется в предпросмотр и форму новой карточки. Перед
сохранением человек может заменить или очистить его. Восстановленный черновик
важнее актуального начального значения. Существующие карточки, их редактирование
и добавление существующей карточки на доску автоматически не заполняются.

API создания карточки применяет значение только при отсутствии ключа поля.
Явно переданные null, пустой текст, false, 0 или пустой список не заменяются.
Обязательность проверяется после этого выбора: очистка обязательного поля
приводит к обычной ошибке, а не скрытому восстановлению начального значения.

Значение хранится отдельно, с типом JSON и ссылкой на поле. Изменение требует
версии поля, прав администратора и принадлежности доске проекта. Вся правка
поля/вариантов/начального значения атомарна. Переключение начального значения
не переписывает существующие значения карточек. Архивирование и восстановление
поля сохраняет настройку. Для списков используются стабильные ID вариантов:
переименование не сбрасывает выбор. Новые варианты доступны для начального
значения после сохранения справочника.

Поддерживаются базовые типы значений, уже существующие в конструкторе. Участник
и связанная карточка остаются явным выбором при заполнении: постоянная ссылка
может потерять доступ и требует отдельного сценария зависимостей. Произвольные
типы, формулы и изменение типа заполненного поля этим этапом не реализуются.

Проверить до выпуска: права и чужой проект, устаревшая версия, неправильный тип,
false/0/список, явная очистка, отсутствие изменения старых карточек, архив/возврат,
предпросмотр без вставок, черновик новой карточки, длинные подписи и 320/1280 px.
Миграция добавляет одну пустую таблицу; все прежние строки сохраняются. Результаты
проверок и фактический выпуск будут дописаны ниже, исторические разделы сохраняются.


## Проверенный сценарий SC-67 — 07.09.2026

На отдельной локальной доске поддержки настроены канал «Почта» и число 0.
Предпросмотр подставил оба значения и не создал карточку. В новой карточке число
изменено на 3; после отмены и повторного открытия восстановленный черновик сохранил
3. После сохранения старая карточка осталась с «Чат», 7 и включённым флагом,
новая — с «Почта», 3 и выключенным флагом. Изменение начального числа на 2
(также через отмену и восстановление черновика настройки) изменило только будущую
форму: обе существующие карточки сохранили данные, количество осталось равным 2.

При проверке 320×740 найдено сжатие закрытия длинным заголовком предпросмотра.
Заголовки настройки поля и предпросмотра получили отдельную колонку кнопки
44×44 px и перенос текста. Ширина содержимого открытых окон 314 px при внешних
320 px, горизонтального переполнения нет. Закрытие в настройках доски, колонки
и поля использует общую кнопку с иконкой. Подпись флага разделена на две строки.
Повторно просмотрены узкая настройка и широкий предпросмотр 1280×800. Настоящие
мобильные устройства в этом этапе не проверялись; использована эмуляция viewport.

Полный go test ./... прошёл (internal/app 53.084 s). После финальных изменений
оформления прошли web Go (1.024 s) и все 228 Node-тестов. Интеграционный тест
начальных значений после расширения прошёл за 0.830 s: права участника, чужая
доска, отсутствие версии, устаревшая версия, типы, 0/false, нормализация списка,
явная очистка, обязательность, старые карточки и архивирование с восстановлением.
Проверка нового варианта из чужого справочника отклоняет изменение и сохраняет
предыдущее начальное значение. Публикация и резервная копия фиксируются отдельно
после фактического выпуска.
