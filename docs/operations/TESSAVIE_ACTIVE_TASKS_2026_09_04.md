### Подготовка выкладки

Маркер оболочки — `20260904-personal-batch-3`. Новые модули встроены в Go-бинарник
и перечислены в статическом allowlist service worker; приватные ответы/файлы
туда не добавляются. Прежние версии emoji, notes, outbox, graph и habits сохранены.

`deploy-personal-batch-20260904.sh` использует прежнюю проверенную схему:
проверка текущего release и SHA → блокировка деплоя → backup SQLite/uploads/
конфигурации → запуск нового бинарника на серверной копии → сравнение всех
старых таблиц → HTTP-проверки → копия непосредственно перед переключением →
короткий перезапуск → локальная и публичная приёмка. Новая миграция 041 добавляет
одну пустую таблицу. Проверяющий скрипт не печатает содержимое приватных строк.
Новая таблица совместима со старым бинарником, откат бинарника не удаляет данные.

`record-personal-batch.py` создаёт временную пятиминутную сессию владельца,
сопоставляет собственные приватные источники и настройки с SQLite, проверяет
404 чужого источника при его наличии и отсутствие личных ID в командном экспорте.
Он не публикует личные материалы на рабочем сервере. Только после проверки
добавляет результаты в две канонические карточки и завершает их без уведомлений
партнёрам. Сессия удаляется в `finally`. Фактические реквизиты будут дополнены
после успешной выкладки; этот раздел описывает подготовленный кандидат.
