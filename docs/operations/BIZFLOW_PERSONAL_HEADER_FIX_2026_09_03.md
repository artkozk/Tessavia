# Выравнивание кнопок личного пространства

## Причина и исправление

На снимке пользователя «Записать» была выше «Календаря». У контейнера details
было `align-self: start`, хотя заголовок выравнивал остальные элементы по центру.
Дополнительное расхождение давало строчное `inline-flex` у summary и разная
минимальная высота кнопок.

Теперь меню наследует выравнивание контейнера, summary использует блочный flex,
оба действия имеют минимум 44 px. На 320 px найден второй случай: надпись
«Календарь» переносилась внутри кнопки, увеличивая её высоту до 52.8 px. Поэтому
действия сохраняют целую подпись и минимальную ширину по содержимому; при нехватке
места переносится само действие, а не часть его названия. Базовые цвета, тексты,
пользовательские настройки страниц, JavaScript и серверная логика не менялись.

## Проверки

1. Пройдены `go test ./...`, `go vet ./...`, 64 Node-теста и отдельная проверка
   CSS-контракта кнопок. Обновлены обе версии URL ресурсов и соответствующий тест.
2. На 1440 px обе кнопки имеют одинаковые y и высоту 44 px.
3. На 390 px обе кнопки расположены рядом и имеют высоту 44 px.
4. Финальная проверка 320 px: y=190.975 у обеих кнопок, высота 44 px,
   ширины 128.01 и 132.79 px. Горизонтального выхода страницы нет.
5. Меню «Записать» открыло редактор заметки. «Календарь» открыл личный календарь.
6. Проверены браузерные снимки; физические Android/iPhone не использовались.

В первом прогоне проверка ассетов обнаружила старый ожидаемый маркер версии;
он обновлён вместе с URL ресурсов. Отдельная старая проверка требует LF в app.js:
свежий Windows worktree получил CRLF, поэтому локальные переводы строк были
нормализованы с сохранением BOM. Git-содержимое app.js осталось неизменным.
