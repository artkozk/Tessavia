# SC-90 — вложенные элементы формы

## Пользовательский результат

Раздел «Вложенные элементы» теперь работает и для формы записи: все подписи или конкретная подпись, все поля ввода или конкретное поле, кнопка отправки, сообщение результата. Это продолжение общего редактора SC-89. Задача `24dace03e01ee45f65328a4ea2e821d0` зарегистрирована в bizflow-team, родитель `b8a99823ccf3f3a9f39093fe3c1af2bf` остаётся открытым.

Причина: оформление внешней рамки формы не позволяет собрать собственное приложение. Пользователю нужны независимые подписи и контролы, общий стиль нескольких полей и индивидуальные исключения. При этом оформление не должно стирать введённый текст, лишать поле доступного имени или ломать обязательность.

## Как пользоваться

1. Выбрать форму в конструкторе своей страницы и раскрыть «Вложенные элементы».
2. Выбрать группу или отдельный элемент. Настроить ширину, минимальную высоту, шрифт, отступы, скругление, цвета, выравнивание и начертание. Поле «Ширина поля (из12)» по-прежнему задаёт размещение в сетке; пиксельная ширина контрола ограничивается этой ячейкой.
3. Проверить предпросмотр под настройками: он показывает поля и пример сообщения результата, не создавая запись. Он обновляется при изменении текста и оформления. Внутри редактора контролы отключены, чтобы проверка вида не выглядела реальным вводом.
4. При необходимости скрыть только визуальную подпись. Сам контрол сохраняет доступное имя через aria-labelledby. Селект сохраняет это имя на видимой кнопке. Идентификаторы подписей уникальны для каждого экземпляра формы: фон страницы и предпросмотр не ссылаются на чужую подпись.
5. Для удаления самого поля использовать «Убрать» в структуре формы. Там остаются действующие проверки обязательных полей и начального названия записи. Размер/цвет не используются для тайного исключения поля из отправки.
6. Сохранить, отменить или восстановить обычный черновик конструктора. «Сбросить выбранный элемент» убирает только выбранное исключение, возвращая общий или исходный вид.

Контролы, отправка и результат не скрываются оформлением: скрытая обязательная ошибка или недоступная отправка сделали бы форму непригодной. Панель объясняет, где убрать поле правильно. Сервер отклоняет попытку скрыть эти элементы напрямую. Визуальные подписи можно скрывать независимо; исходные значения и поля сохраняются.

Для селекта оформляется видимая кнопка; нативный select остаётся техническим контролом существующей реализации. Для чекбокса и вариантов множественного выбора размеры относятся к строке выбора, а не растягивают маленькую галочку. Чекбокс сохраняет собственное имя, множественный выбор — имя группы и подписи вариантов. Обработка значений и обязательности остаётся штатной.

## Совместимость и данные

Новые ключи elementStyles: formLabel, formControl, formSubmit, formResult; индивидуальные formLabel:ключПоля и formControl:ключПоля, например formControl:custom:ID. Сервер разрешает только существующие встроенные ключи или корректные ID полей своей доски. Перенос набора переводит custom ID на новую схему общим механизмом elementFieldID. Проверяются роли, принадлежность полей и expectedRevision.

Ранее formFields содержал общие fontSize/color/background. При открытии конструктора эти свойства переводятся в индивидуальные стили подписи и контрола; фон относится к контролу. Уже заданные новые свойства имеют приоритет. Старые три поля удаляются только из редактируемой конфигурации, чтобы после сброса не возникал невидимый второй источник оформления. Сетка, подписи, подсказки, скрытие и порядок сохраняются. Без сохранения страницы серверная конфигурация не меняется. Повторное преобразование ничего не добавляет. Прежние страницы продолжают отображаться до открытия редактора. Историческая документация SC-77 остаётся описанием прежней схемы.

Оформление не меняет значения контролов при применении. Введённый черновик восстанавливается даже после изменения вида формы; штатное предупреждение просит проверить изменившуюся форму. Отправка использует прежний механизм устойчивого намерения и Idempotency-Key. Набор не содержит записи автора или локальный черновик ввода.

Миграций БД нет, схема065/117таблиц. Откат к SC-89 запрещён при сохранённых ключах formLabel/formControl/formSubmit/formResult: прежний сервер их не понимает. Проверка выполняется после остановки службы. Старые обычные elementStyles сами по себе откат не блокируют.
