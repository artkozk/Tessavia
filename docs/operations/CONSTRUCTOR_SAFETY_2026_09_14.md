## Что воспроизведено до изменения кода

На локальной синтетической SC-94 открыто сохранение расчётного листа как своего
блока. Введены имя «SC-100 Расчёт цены заказа с материалами» и описание. После
закрытия редактора и повторного открытия формы имя вернулось к «Оценка работы»,
описание стало пустым. Рабочие числа листа и пользовательские данные не менялись.

На синтетической SC-85 исходный список имел действие из двух изменений и условие.
В интерфейсе выбран тип «Текст», затем обратно «Список записей». Число действий
изменилось с 1 на 0 без предупреждения; последующий возврат типа их не восстановил.
Диагностический черновик отменён кнопкой «Отменить изменения», на сервер не сохранён.

Независимая исполняемая проверка обнаружила дополнительный тупик: 40 скрытых блоков
занимают весь лимит страницы, но интерфейс вставки предлагает освободить место,
не предоставляя операции удаления. Это отдельный этап, не исправленный данным выпуском.

## Реализация и приёмка окончательного кандидата

Контракты: `COMPONENT_DRAFTS_2026_09_14.md` и `BLOCK_KIND_SAFETY_2026_09_14.md`.
Метаданные компонента сохраняются отдельно от изменений дерева в существующем
ключе черновика; успешная операция очищает только свой корень. Исправляемая ошибка
возвращает ту же форму, неизвестный результат хранит прежний запрос и его ID.
Защита типа перехватывает `input` и `change` до изменения конфигурации; объяснение
возле свойств переводит фокус к выбранному типу в существующем каталоге блоков.

Окончательный кандидат собран из экспорта Git index с LF для Windows и Linux amd64.
486/486 Node-тестов PASS; `go test ./...` PASS (internal/app 128.632 s),
`go vet ./...` PASS. Проверка процедуры: 17/17 verifier, Python syntax и `bash -n` PASS.
Независимый просмотр release-скриптов не обнаружил блокирующих ошибок.

Фактически пройдено через GUI на синтетической странице SC-85:

1. При выборе «Текст» у списка с действием селектор остался «Список записей»;
   действие из двух изменений, условие, поля и оформление остались на месте.
   Предупреждение просмотрено на 320×740. «Выбрать другой блок» перевело фокус
   на кнопку «Текст» в существующем каталоге, без создания блока автоматически.
2. Добавлен соседний текстовый блок «SC-100 Памятка для нового заказа», свободно
   переключён в заголовок, страница сохранена. После reload и повторного открытия

3. Созданы два разных черновика метаданных: для списка и для нового заголовка.
   После закрытия и повторного открытия имя и описание заголовка восстановились,

   На 320 px форма, многострочный предпросмотр, пояснение и кнопка не выходят за экран.

   заменил ответ на 503 после задержки 4 секунды. Интерфейс предложил проверить
   результат. Редактор закрыт, браузер перезагружен; после восстановления черновика

   запись с заданным уникальным SC-100 названием и исправленным описанием.
6. У второго корня остались прежние имя и описание. Они сохранились также после

   У успешно сохранённого корня новый вызов формы показал исходный заголовок и
   пустое описание: очищен именно завершённый черновик. Ошибок JavaScript не выявлено.

Proxy обслуживал только localhost 38543 → 38544, не журналировал тела и заголовки.
Производственные данные и трафик не использовались. Проверки изоляции ключей,
устаревшего обработчика, 409 и сохранности метаданных при вставке выполнены
автоматическими тестами; они не выдаются за ручную приёмку на реальных телефонах.
