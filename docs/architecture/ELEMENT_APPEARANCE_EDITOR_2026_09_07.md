# Настройка элементов: размеры, текст и оформление

Новый прямой запрос пользователя 07.09.2026: настраивать все элементы, включая размеры, цвета, текст и типы. Прежний редактор не удовлетворяет этому требованию: изменение геометрии применялось только внутри специальной сетки; на чтении параметры сохранялись, но CSS не использовал их. Палитра по умолчанию остаётся прежней, новые цвета являются явной личной настройкой пользователя.

Первый исправляемый механизм — общие свойства блоков и вложенных элементов: размеры, текст, цвет текста/фона, размер шрифта, отступы и скругление с возвратом исходного вида. Редактор должен показывать применимые свойства выбранного элемента, предварительный результат, отмену и сохранение в своём проекте/странице/устройстве. Пользовательские настройки не переписывают бизнес-значения и общие схемы. Смена типа бизнес-поля требует отдельного предпросмотра преобразования по задаче 2092665a817cc23073154bc1adf06377; нельзя подменять её CSS-оформлением.

Проверить: геометрия чтения вне прежней общей сетки, настройки вложенной кнопки/подписи/поля, сохранение/reload, отмена/сброс, длинный текст, цвета без HTML/CSS-инъекций, мобильный профиль, сохранность данных. Исторические ограничения SC-72 сохраняются в документах как описание предыдущего выпуска.

## Уточнение масштаба владельцем

После начала аудита пользователь прямо уточнил: нужны не только свойства внешнего вида. Человек должен собирать собственные приложения и сценарии, в том числе аналог читалки, через интерфейс. Поэтому приоритет — переиспользуемые блоки, пользовательские данные/элементы и действия. Работа по размерам/цветам сохраняется как часть этого конструктора, но сама по себе не выполняет запрос. Первым сквозным примером служит трекер чтения/обучения, созданный пользователем с пустой страницы. Полная эквивалентность готовой читалке (книги, рейтинг, группы, расписания, дневник) требует дальнейших блоков и связей; нельзя объявлять её реализованной первым примером.
