# Выпуск Tessavie: название, логотип и оформление

## Подготовленный объём

Прямой запрос пользователя от 03.09.2026 утвердил Tessavie. Изменены видимые
названия, логотип, вход, общая палитра, favicon/PWA и имена экспортов.
Миграция 029 обновляет только исходные имена встроенной команды и проекта.
Подробные причины и границы: [контракт бренда](../architecture/TESSAVIE_BRAND_CONTRACT_2026_09_03.md).

В основной папке проекта есть параллельные незакоммиченные изменения команд.
Этот выпуск изолирован от них отдельной веткой и рабочей копией.
На первом подтверждённом SSH-чтении рабочий сервис active, текущая сборка
`20260903-workspace-widgets-day-158a3d8`, последняя миграция 026.
Старые отображаемые имена обеих встроенных сущностей подтверждены.

Найдена существующая задача `9b40463ee2ec5e93d91309bd34b2e5f8` о возвращении
к бренду после отдельного решения. Её описание прочитано; прежняя история
сохраняется, технический выпуск оформляется отдельным дочерним этапом.

## Проверки перед выкладкой

Серверные тесты, включая три случая миграции, прошли. Node: 64/64.
В процессе проверки устранена зависимость чтения встроенного JS от CRLF:
`.gitattributes` закрепляет LF для `web/app.js`, чтобы Windows и Linux проверяли
одинаковый файл. Существующая проверка метки CSS/JS обновлена на три ресурса
выпуска Tessavie. После исправления `go test ./...` и `go vet ./...` прошли.

На этом этапе документ фиксирует подготовку, а не завершённый деплой.
Фактические коммит, backup, SHA, release и результаты добавляются ниже после
успешного выполнения скрипта и проверки публичного адреса.

## Приёмка интерфейса и запись этапа

В проекте `bizflow-team` через штатный API создан и повторно прочитан дочерний
этап `c0fd9c05fb729716cc0fcee1392673e4`: «Выпустить Tessavie: новое имя, логотип и
оформление». Родитель дополнен новым решением без удаления прежнего описания.
Его общий статус сохранён, поскольку внешняя регистрация бренда не подтверждена.
Служебная сессия удаляется в finally; секреты не включены в код и отчёты.

Локальная искусственная база: вход, экран обзора и мобильное меню проверены.
На 320 px длинный заголовок заметки и текст введены, Escape закрыл редактор;
повторное открытие показало «Восстановлен несохранённый текст» и исходное содержимое.
После сохранения заметка появилась в списке. Ширина диалога и страницы — 320 px.
На 390 px проверено меню поверх рабочих блоков. На 820 px форма регистрации
имеет одну колонку шириной около 438 px, а декоративная половина скрыта.
На 1280 px проверены весь рабочий экран, читаемость меню и отсутствие горизонтального
выхода. Формы 320/390 px также не выходят за границы. Это проверка viewport,
а не реальных телефонов.

Оба экспорта с локальной авторизацией вернули 200 и новые Content-Disposition:
`tessavie-records.csv`, `tessavie-export.json`. Старое имя в видимом DOM отсутствует.
В рабочие данные сервера тестовые заметки и экспортируемые данные не добавлялись.

## Совмещение с открытием регистрации

Во время подготовки появился коммит `df1c07a` с фактическим открытием регистрации.
Он включён merge-коммитом в ветку ребрендинга. Текущая серверная сборка при этом
не менялась. Текст входа теперь «Ваше пространство», поскольку закрытой является
командная информация по правам доступа, а регистрация уже открыта.
Деплой сохраняет актуальный `/etc/business-control.env`: ограничения не возвращаются
и значения секретов не печатаются. Незакоммиченный жизненный цикл команд остаётся
отдельной работой и в бинарник этого выпуска не входит.

## Первый пробный запуск

В 08:11 UTC создан backup
`/var/lib/business-control/backups/pre-tessavie-brand-20260903T081121Z`.
SHA256 подтверждён; сравнение всех пользовательских таблиц на копии вернуло
`DATA_PRESERVATION=ok`: допустимы только два стандартных имени и их updated_at.

Проверка CSS остановилась с `curl: Failed writing body`: `grep -q` завершался
после нахождения цвета раньше, чем curl дописывал ответ в pipe; `pipefail` правильно
остановил выпуск до переключения. Исправление сохраняет ответы CSS и manifest
во временные файлы, затем проверяет содержимое. Это исключает ложный сбой smoke.
Production остался на `20260903-workspace-widgets-day-158a3d8`, сервис active.
Неуспешный кандидат оставлен в releases для истории, пользовательская база не
заменялась. Повторная выкладка получает отдельное имя release и свежую копию.
