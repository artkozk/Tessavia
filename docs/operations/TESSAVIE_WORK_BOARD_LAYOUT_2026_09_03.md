# Положение доски на странице «Работа», 3 сентября 2026

## Запрос и причина

Пользователь показал пустую пользовательскую доску, расположенную выше заголовка,
поиска и настройки её полей. Переместить её через редактор страницы было нельзя.
Задача в проекте разработки: `7a5daf6b995bf8a4b6503e943dee828c`, ответственный
artkozk. Родительское направление `46fd28bb741370595fbb75a553121349` не закрывается.

Причина: `renderWorkCollectionBoard` возвращает `.collection-board`, а каталог
блока `records` в «Работе» распознавал только стандартный канбан, таблицу и календарь.
Общий редактор перемещал распознанные элементы в сетку в конце страницы. Доска
оставалась вне этой сетки, выше управления, без ручек перемещения и размера.
Это не пользовательская настройка и не причина сбрасывать её профиль.

## Изменение

1. Зарегистрирована доска с пользовательскими этапами как тот же блок `records`.
   Порядок без сохранённого переопределения: заголовок, поиск и фильтры, сводка,
   выбор доски с настройками, карточки доски. Исправление работает и для пустой доски.
2. Редактор называет поверхность по открытому виду: «Доска», «Календарь» или
   «Карточки». Панель управления названа «Доска и её настройки», чтобы её не путали
   с самой доской. Новые дублирующие кнопки в обычном режиме не добавлены.
3. Стабильные ключи `records` и `boards` сохранены. Работают прежние ручки
   перетаскивания, клавиатурный перенос, геометрия, сохранение и отмена.
   Явно сохранённый пользователем порядок имеет приоритет над порядком по умолчанию.
   Настройки ПК/телефона, других страниц и проектов не переписываются.
4. Меняется маркер загрузки CSS/JS. Внешний вид, название Tessavie, базовая палитра,
   регистрация без кода и данные команды сохраняются. Миграций нет.

## Как изменить порядок

Открыть «Работа», выбрать вид «Доска», затем «Настроить страницу» в верхней панели
или через «Настроить меню → Настроить страницу». Выбрать ПК/телефон, перетащить
ручку с точками у блока «Доска», нажать «Сохранить». На сфокусированной ручке также
работают стрелки, Home и End. Сброс в редакторе относится только к текущей странице
и выбранному устройству. Сама доска не удаляется при перестановке.

- Регрессионный тест проверяет один ключ содержимого и порядок после управления
  для списка, встроенного канбана, доски с собственными этапами и календаря.
- `go test ./...`, `go vet ./...`, 68 Node-тестов прошли.
- На искусственной базе `127.0.0.1:8536` проверены пустая пользовательская доска,
  сохранение порядка после перезагрузки, отмена перестановки и независимость
  мобильного профиля от сохранённого порядка ПК.
- На ПК проверено настоящее перетаскивание мышью и перенос с клавиатуры.
  На 1440 px верх доски 547 px, низ панели управления 529 px: перекрытия нет.

## Выпуск и ограничения

`deploy/deploy-work-board-20260903.sh` использует блокировку, сверяет предыдущий
release и SHA, сохраняет БД/uploads/env на том же сервере, запускает кандидата
на копии и сравнивает строки всех таблиц. Только после этого переключает бинарник.
При неудачной проверке после переключения возвращает предыдущую сборку.
Скрипт не меняет конфигурацию регистрации или права пользователей.

Незавершённый аудит жизненного цикла команд не включён в эту сборку. Полноценные
пользовательские типы, программируемые связи и переносимые инструменты без кода
остаются отдельным запросом. Этот выпуск не объявляет их реализованными.
Фактические release, commit и результаты проверки сайта добавляются после деплоя.

### Завершение локальной проверки

На 390 и 320 px порядок по умолчанию не изменился и горизонтального переполнения
документа нет. На 320 px верх доски 873 px, низ панели управления 855 px. Длинная
карточка переносит название внутри колонки и открывает исходную запись. Меню
состояния отображается поверх карточек; выбор «Завершённые» скрывает активную
тестовую карточку, выбор «Все» возвращает её. Ошибок консоли в сценарии нет.

Проверены отмена несохранённого переноса и возврат сохранённого порядка, перенос
мышью через ручку, клавиатурный перенос и сохранение. Тестовые аккаунт, команда,
доска и карточка созданы только в отдельной локальной базе. Физический телефон
не использовался: проверена браузерная мобильная ширина.
